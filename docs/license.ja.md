## 第三者部分と出力

[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)に各構成要素・参考資料・権利表示を記載しています。
cq-acis とその Rust crate は独自の MIT 条件を維持します。
CadQuery・OCP 等の Python 依存は別配布物です。OEM インストーラーへ同梱する場合は、
内部のネイティブライブラリも含め、各条件に対応してください。

配布物の複合 SPDX 式は構成要素や出典資料それぞれの条件を示すもので、全ファイルの
選択ライセンスではありません。プロジェクト全体を MIT や Apache-2.0 で利用できるという
意味ではありません。本文は wheel metadata、sdist、各 Rust crate、Viewer に収録します。

変換した CAD・画像・属性へ、当社の追加所有権や出力単位のロイヤリティを設定しません。
入力データや第三者の権利は別途適用されます。公開サンプルをダウンロードできることから
再配布権を推認しないでください。
