0.2.0 にもあった API や機能だけを呼び出すことによって、現行配布物に含まれる
その後の追加・改修部分の条件が免除されるわけではありません。

| 利用する素材・配布物 | 適用する許諾 |
| --- | --- |
| 新条件の素材を含む現行の配布物 | その素材についての PolyForm または別途商用契約と、該当する MIT・第三者の条件 |

商用契約では、個別の API 呼び出しや新機能だけを課金対象にするのではなく、
対象リリース・配布物・利用形態を定めます。PolyForm、MIT、その他の適用ライセンスで
既に認められている利用について、同じ権利を当社から購入する必要はありません。

## 利用形態

| 利用 | 適用する条件 |
| --- | --- |
| 商用化を予定しない個人の学習・趣味 | PolyForm 本文の許諾範囲 |
| 教育機関・公的研究機関など本文に明示された組織 | 資金源にかかわらず、公式本文の許諾を適用 |
| 企業の業務自動化、社内変換、商用開発 | PolyForm の許諾外の用途は Commercial Internal |
| 顧客へ配る製品への組込み | Commercial OEM。同一法人の Internal 利用を含む |
| 他社が製品を開発するための SDK 再提供 | SDK 再提供の追加条項 |
| 顧客向けの変換・解析サービス | SaaS の追加条項 |
| 企業による導入可否の評価 | 別途30日間の評価許諾を依頼 |

小規模企業という理由だけの無料枠は設けません。社内利用も自動的に非商用とはなりません。

大学の許諾が別法人の企業にも自動的に及ぶとは扱いません。
PolyForm には配布の許諾もあります。コピーを渡すことと、受領者に商用実行・開発の権利を
与えることは区別します。

見積・範囲・契約満了・OEM 顧客の実行権・サポートは

## 存続する旧 MIT の権利

0.1.0、0.2.0 と、以前 MIT で公開したソースの許諾は存続します。
公開済みコミット [`440f149`](https://github.com/monozukuri-ai/inventor-kit/tree/440f149fe96a4c8e7f207ce621919284f6a1f621)

[inventor-kit-legacy-MIT.txt](../licenses/inventor-kit-legacy-MIT.txt)に原文のまま保存しています。
ソースの切替は新しい LICENSE 表示を導入した最初のコミット、パッケージの切替は
0.3.0 です。旧コードを新版へ含めても、その MIT 許諾は撤回しません。

その素材が現行ソース内に含まれる場合も、以前 MIT で公開された素材と確認できれば、
その MIT 許諾は独立して存続します。この案内は、過去の配布物の条件を遡って変更しません。
個々の利用をどの許諾で行えるかは、バージョン番号や API 名だけで決まるものではありません。

旧配布物が必要な場合は `inventor-kit==0.2.0` と依存関係の lockfile を固定してください。
固定によって将来の修正や互換性が保証されるわけではありません。
旧表示は、その後のすべての追加実装へ MIT を適用するものではありません。

## 第三者部分と出力

[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)に各構成要素・参考資料・権利表示を記載しています。
cq-acis とその Rust crate は独自の MIT 条件を維持します。
CadQuery・OCP 等の Python 依存は別配布物です。OEM インストーラーへ同梱する場合は、
内部のネイティブライブラリも含め、各条件に対応してください。

配布物の複合 SPDX 式は構成要素や出典資料それぞれの条件を示すもので、全ファイルの
選択ライセンスではありません。プロジェクト全体を MIT や Apache-2.0 で利用できるという
意味ではありません。本文は wheel metadata、sdist、各 Rust crate、Viewer に収録します。

変換した CAD・画像・属性へ、当社の追加所有権や出力単位のロイヤリティを設定しません。
入力データや第三者の権利は別途適用されます。公開サンプルをダウンロードできることから
再配布権を推認しないでください。
