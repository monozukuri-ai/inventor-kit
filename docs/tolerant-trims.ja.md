# トレラント境界・有限 UV

[English](tolerant-trims.md) | 日本語

通常ビルドと fuzz の Rust 依存を、公開済みの `acis-core=0.3.4` と
`acis-py-bridge=0.3.4` に更新しました。Python は `cq-acis>=0.3.4,<0.4` を必要とします。
共通モデル API 2 は変わりません。公開0.3.4には有限 spline 定義域、次数1／3の保存 UV ビュー、
曲線と支持面の独立した向き、TEDGE の局所上限による変換が含まれます。
以下の新しい追加対応は未公開で、対応する cq-acis ソースが必要です。

## 検証方法

```sh
python scripts/validate_components.py
python scripts/validate_topology.py
python scripts/validate_tolerant_trims.py
python scripts/validate_geometry.py
```

固定 fixture の hash を検査し、`internal/reports/latest/` に詳細を保存します。
トポロジー・トリム検査は FTC07 2021 回帰を使用し、全体の形状検査では独立 holdout と固定ソリッド量も確認します。
版番号、読み込んだモジュールの場所、元バイトの hash、source span、subtype 所有者、適用上限、実測偏差を記録します。
追加 native API の有無で、公開0.3.4と開発ソースの期待値を分けて検査します。

## 未公開の inline／支持曲線対応

10件の inline coedge にある観測済み full `par_int_cur` を読み取り、3次の保存3D fit、支持面、
次数3または有理2次の保存 UV、元レコード内の位置を保持します。
平面の UV 倍率と球・トーラスの角度順序を明示的に扱います。
inline fit とその支持面の偏差、変更していない共有辺と UV の TEDGE 上限は独立に検証します。
平面上の有理円弧2件は、曲線全体の円錐曲線残差と角度の単調性などで同じ小円弧であることを確認できたため、
OCCT の解析辺にパラメータを合わせます。元の制御点は raw モデルに保持します。

検証済み inline 使用側の局所上限で、保存トレラント端点と同じ頂点 ID の UV 接続を確認します。
通常の直線は、保存点が同じ直線上かつ元の区間内にある場合に限って、その点まで区間を狭めます。
平面の穴の向きも全ての辺を保持して調整します。
モデル全体の精度、有限 UV 領域、共有3D曲線、意味未確定の TVERTEX 数値を変えて不一致を通しません。

`NativeModel.supported_curve()` は曲線4022の full `int_int_cur` を読み取り、
file-local spline 支持、第2支持平面、保存 UV、末尾情報を保持します。
保存3D fit の全区間を両支持面に対して検証し、保存 UV との元の同一パラメータ偏差も別途記録します。
各支持面への距離の検証であり、厳密な交線を保証するものではありません。
この曲線の端点と保存頂点の照合は、接続する2面で元のモデル精度を超えます。

## ローカル結果（2026-09-13）

| 検査 | 公開0.3.4 | 開発ソース |
| --- | ---: | ---: |
| inline coedge の読み取り | 0 / 10 | 10 / 10 |
| 有効なトレラント coedge の辺 | 195 / 206 | 206 / 206 |
| FTC07 の有効な個別面 | 245 / 258 | 254 / 258 |
| 有限 UV を持つ有効な面 | 5 / 8 | 5 / 8 |
| 読み取れた有限 spline 支持面 | 8 | 8 |
| 保存 spline pcurve ビュー | 224 | 224 |

以前から有効だった245面の面積は全て同じです。
新たに有効になった面 ID は1524、1535、1994、1997、2782、2822、2977、2998、4162です。
全33ファイルでは有効ソリッド10件（回帰9、holdout 1）と、既存の固定ソリッド量を維持しています。

残る4面は次の理由で拒否します。

| 面 ID | 不一致 | 実測／上限（mm） |
| --- | --- | --- |
| 1164 | 保存 pcurve と TEDGE | 0.006255113958 / 0.006130569677 |
| 2336 | 保存 pcurve と TEDGE | 0.006246879672 / 0.006109190844 |
| 332、4351 | 曲線4022と頂点3618の端点 | 0.006526083452 / 0.000010 |

保存 pcurve の2面は、再パラメータ化の試行でも元の辺の上限を満たしません。
投影した代替 UV は有限領域を出るため採用していません。
spline 端点の不一致は、従来の inline／曲線未対応の後ろに隠れていたものです。
意味未確定の頂点数値で許容差を広げず、FTC07 全体は引き続き `geometry.pcurve_mismatch` で拒否します。
これはローカルでの出典・形状整合性の検査であり、Inventor／現在の Model State、
Windows／macOS、リモート CI の合格を示すものではありません。
